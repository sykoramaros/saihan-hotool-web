# Saihan Hotool — Claude Code Instructions

## Project overview

React 19 SPA for a Mongolian yurt camp. Single-page app with hash-anchor navigation. All content comes from Strapi CMS via GraphQL. Supports i18n (Czech/Mongolian) via LanguageProvider.

Built on the same base as `project_template` — Vite, TanStack Router (file-based), TypeScript, Tailwind CSS v4, shadcn/ui. Apollo Client and LanguageProvider are project-specific additions.

## Tech stack

- React 19, TanStack Router v1 (file-based, single `/` route)
- Tailwind CSS v4 + shadcn/ui (Radix UI primitives)
- Apollo Client v3 + GraphQL (Strapi CMS: `https://strapi-saihan-hotool.marosh.uk`)
- Vite 7, TypeScript (strict)
- lucide-react for icons
- No react-router-dom, no Bootstrap, no react-router-hash-link

## Hash navigation

All page sections are on `/`. Navbar links use JS scroll (not anchor hrefs):
- Home → scroll to top
- Info → `#info` (offset 80px for sticky navbar)
- Pricing → `#prices` (offset 80px)
- Gallery → `#carousel-gallery` (offset 80px)
- Contact → `#contacts` (footer wrapper)

## Custom CSS classes (defined in index.css)

- `.app-container` — animated gradient background (fixed, z-index: -999)
- `.carousel-container` — pill-shaped carousel with decorative box-shadow
- `.hide-scrollbar` — hides scrollbar on the horizontal price section
- `.language-container` / `.language-container.open` — floating circular language switcher
- `.cookies-modal-container` — fixed-position cookies banner
- `.modal-backdrop` / `.order-modal` — order modal overlay
- `.text-shadow-black` / `.text-shadow-white` — text shadow utilities

## Custom Tailwind colors (defined in @theme)

- `primary` → `#ffd88a` (warm yellow)
- `secondary` → `#a3d4f7`
- `success` → `#6b8e23` (olive green)
- `info` → `#6faedb` (sky blue — used for language switcher)
- `warning` → `#8b5e3c` (brown — used for mobile menu background)
- `dark` → `#2e3b2d`

## Development

```bash
npm run dev      # Vite dev server on :5175
npm run build    # production build → dist/
npm run preview  # preview the dist/ build
```

## Deployment

Frontend is served by an Apache container on a local server.

```bash
npm run deploy   # builds → dist/, rsync to server, restarts Docker container
```

`deploy.sh` reads credentials from `.env.deploy` (not committed).
